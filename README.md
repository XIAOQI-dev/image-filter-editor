# 🎨 在线图片编辑器

一个纯前端实现的在线图片编辑工具，支持裁剪、滤镜、调色、旋转翻转，所有处理都在浏览器本地完成，无需上传服务器。

## ✨ 功能特性

- 📤 图片上传（本地选择）
- ✂️ 交互式裁剪（拖拽选区）
- 🔄 旋转 / 水平翻转 / 垂直翻转
- 🎭 6种滤镜预设：原图、暖阳、冷调、复古、黑白、胶片
- 🎚️ 精细调节：亮度、对比度、饱和度、灰度、模糊、棕褐
- 💾 导出 PNG 格式图片

## 🛠️ 技术栈

- 原生 HTML5 / CSS3 / JavaScript (ES6+)
- Canvas 2D API（图像绘制、像素操作）
- Canvas Filter API（CSS filter 滤镜）
- 无任何框架依赖，单文件即可运行

## 🚀 快速开始

直接用浏览器打开 `index.html` 即可使用。
